# 石溪 (ShiXi)

**餐饮经营诊断系统** — 给数据，出诊断报告。

> 小谷姐姐麻辣烫·威海石岛湾店专用，可扩展到其他品类。

## 一句话

把美团管家导出的菜品销售明细扔进来，自动分析：**哪有问题、怎么改、接下来会怎样**。

## 快速开始

```bash
# 1. 导入美团导出的Excel
python3 -m shixi.cli ingest 菜品销售明细.xlsx

# 2. 生成诊断报告
python3 -m shixi.cli report

# 3. 查看数据概况
python3 -m shixi.cli info
```

报告自动保存到 `reports/shidaowan_YYYYMMDD.md`，每天覆盖当天的。

## 分析维度

| 角度 | 诊断什么 | 核心问题 |
|------|---------|---------|
| 客群画像 | 谁在吃你的麻辣烫？ | 核电站工人、学生、渔民、留守妇女、游客——各来了多少、怎么接住 |
| 称重结构 | 客人拿多少？ | 每碗几斤？中位数往下掉了吗？ |
| 口味格局 | 几种口味活得怎么样？ | 哪个在涨、哪个在跌、哪个一家独大？ |
| 食材备料 | 哪些赚钱哪些占位？ | 生鲜类卖不掉是真亏，冻品类卖不掉只是占位 |
| 客人行为 | 怎么吃、还买了什么？ | 米饭搭了吗？饮料推了吗？一个人来还是结伴？ |
| 时段效率 | 赚钱还是白烧？ | 午晚高峰利用率、下午空窗要不要关门？周末该多备料吗？ |
| 位置变现 | 石岛湾这个位置用上了吗？ | 海水浴场的游客能走到你店吗？核电站工人路过吗？ |
| 策略推演 | 爸妈能做的下一件事 | 不搞复杂活动，不上外卖——只做老人能操作的事 |

## 店铺约束

- 无外卖（雇人挑剔，暂不开）
- 不做复杂营销活动（父母精力有限）
- 无会员系统
- 无成本记账
- 仅美团管家POS收银

系统自动遵守以上约束，不会建议"搞个会员体系"或"做抖音营销"之类的事。

## 店画像

每个店一个 YAML 文件，位置在 `shixi/config/stores/`。内容包括：

- 地址坐标
- 周边环境（小区、景点、学校、商业）
- 客群定义（谁来吃、什么特点、现在有没有服务到）
- 本地特征（旅游季月份、饮食习惯）
- 经营约束（什么不能做）

当前已配置：**小谷姐姐麻辣烫·威海石岛湾店**

## 分析报告的要求

1. **每天覆盖** — 每次跑 `shixi report` 生成当天报告，文件名含日期
2. **增量对比** — 导入新数据后，对比上期报告看变化趋势
3. **结合调整** — 如果店里做了什么改动（比如换招牌、改菜单），在新报告中分析效果
4. **建议可操作** — 每一条建议都必须是父母能执行的（不考虑外卖、不考虑复杂活动、不考虑需要手机操作的事）
5. **客群覆盖** — 六个客群（本地居民、核电工人、学生、渔民、留守妇女、游客）逐个分析
6. **不编造数据** — 没有成本数据就不分析毛利，没有会员数据就不分析复购。实事求是
